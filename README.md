## 📌 Sobre o Projeto

O projeto tem como foco expandir as capacidades do **BEBoP**, uma ferramenta criada para verificar a compreensibilidade de modelos de processos de negócio. A pesquisa explora a implementação de novas funcionalidades e a estruturação de um sistema para classificar as melhores práticas de modelagem. Durante minha atuação neste projeto (Set 2025 - Atual), o objetivo principal tem sido aprimorar a ferramenta para torná-la mais eficiente e analítica para os usuários.

## ✨ Principais Contribuições e Funcionalidades

* **Desenvolvimento backend:** Desenvolvimento de novas funcionalidades na ferramenta BEBOP utilizando Java.
* **Inspeção de qualidade:** Foco na análise e priorização de boas práticas em modelagem de processos (BPMN).
* **Desenvolvimento apoiado por IA:** Utilização de Inteligência Artificial como ferramenta auxiliar durante o ciclo de desenvolvimento, contribuindo para a escrita, otimização de código e na aceleração da resolução de problemas complexos.
